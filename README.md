# Coruja Matematica

Jogo educativo de matematica do 6.o ano, em portugues.

## Instalar
```bash
npm install
npm run setup
npm run dev
```

## Verificar
```bash
npm run typecheck
npm run test
npm run build
```

## Conteudo
Os exercicios sao gerados por `scripts/generate-content.mjs`. Nunca editar a mao.
